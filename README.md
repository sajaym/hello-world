# Audiobook Player

This is a simple audiobook player that displays subtitles from an SRT file synchronized with an MP3 audio file.

## How to use

1.  Replace the `sample.mp3` file with your own MP3 audio file. Make sure the file is named `sample.mp3` or update the filename in `script.js`.
2.  Replace the `sample.srt` file with your own SRT subtitle file. Make sure the file is named `sample.srt` or update the filename in `script.js`.
3.  Open the `index.html` file in a web browser.

The player will load the audio and subtitles, and you can use the controls to play, pause, and seek through the audio. The subtitles will be displayed in sync with the audio.
